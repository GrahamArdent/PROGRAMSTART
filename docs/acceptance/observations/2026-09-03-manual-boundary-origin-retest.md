# Manual-boundary origin retest — 2026-09-03

## Evidence

Two independent Mode-C projects exposed the same classification defect.

1. `GrahamArdent/whats` lawyer-disclosure work: a Windows/operator command was initially described as the remaining human gate even though the command itself was mechanical. The genuinely human-sensitive boundaries were evidence-source ambiguity, disclosure scope, and authorization. PROGRAMSTART issue #90 captured this first case.
2. `GrahamArdent/resume_creator_v5` M1: repository-local acceptance, baseline comparison, contract reconciliation, tests, and a normal branch push were already authorized. Termius became transport only because the current ChatGPT/GitHub surface lacked a proven execution-node actuator. Subsequent control-plane work confirmed that this was an execution-capability gap rather than human judgment.

## Learning Gate

The existing Effective Autonomy protocol already targets zero human transport work while preserving genuine human judgment. The earned clarification is narrower and explicit:

- classify the boundary origin before declaring a human gate;
- `genuine_human_gate` is reserved for intended human judgment, authorization, physical action, secret entry, legal/business acceptance, or equivalent human evidence;
- `temporary_automation_gap` covers mechanical already-authorized work that is manual only because a Controller, Compute Spine, worker, identity, or tool actuator is not currently proven;
- current-environment inability alone is not evidence of a genuine human gate;
- temporary relays remain removable debt and should route to the capability owner without weakening real consequence gates.

This is a methodology clarification, not a new lifecycle, scheduler, permission source, or universal shell actuator.

## Infrastructure ownership

Compute Spine issue #36 owns the execution-fabric remediation. The repository workspace executor merged in Compute Spine PR #37 is the bounded permanent direction, while live credential isolation and worker/toolchain activation remain independently gated.

Resume Creator M1 is the first natural retest. Success means PROGRAMSTART treats the remaining terminal-style work as a temporary automation gap, continues safe repository work automatically, uses an already-authorized actuator when available, and stops only if a genuine approval/security/evidence gate is reached.
